Follow the steps below to set up and run the project locally :-

1. Clone or Download the Repository
First, download or clone this repository to your local machine.
git clone <repository-url>
Or simply download and extract the ZIP of the project.

2. Open the Project in VS Code
Open the entire project folder in Visual Studio Code.

-> Run the Project
The project consists of two parts: Backend and Frontend. Follow the steps below to run both:

Step 1: Start the Backend
Open a terminal in VS Code.
Navigate to the backend folder:
"cd backend"

Run the following command:
"npm run dev"
 This will start the backend server.

Step 2: Start the Frontend
Open another terminal in VS Code.
Navigate to the frontend folder:
"cd frontend"

Run the following command:
"npm start"
 This will start the frontend development server and the website will open in your browser.
